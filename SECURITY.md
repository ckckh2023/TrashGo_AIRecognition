# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

**Private report email**: fightened2023@foxmail.com | Tangibledreams@yeah.net

**Response time**: We will acknowledge receipt within 72 hours.

**Please include**:
- Clear description of the vulnerability
- Steps to reproduce
- Affected versions

**Do not** disclose the vulnerability publicly on GitHub Issues, forums, or chat groups.

**What to expect**: If accepted, we will fix it and publish a security advisory. If declined, we will explain why.
