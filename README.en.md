## Project Introduction

TrashGo is an intelligent tool that integrates multiple image information recognition capabilities, designed to help users quickly identify images, text, voice, and more, while providing an engaging and interactive experience. Whether it's waste sorting or face recognition, TrashGo handles it with ease.

## Features

- **Waste Sorting Recognition**: Take a photo to identify the waste category and get proper disposal guidance.
- ~~**Face Recognition**: Detect faces and analyze attributes such as age and expression.~~
- ~~**Fun Mini‑Games**: Waste sorting challenges, picture quizzes – learn while playing.~~
- **History**: Save all recognition records, support search, filter, and sharing.
- **Dark Mode**: Adapt to system dark theme for a more comfortable night‑time experience.
- ~~**More Settings**: Language switching, recognition precision adjustment, cache cleaning, etc.~~

## Installation Guide

### Download Installer
- **Windows/Linux**: Download the latest installer from [Releases](https://github.com/ckckh2023/TrashGo_AIRecognition/releases).

### Build from Source
1. Clone the repository: `git clone https://github.com/ckckh2023/TrashGo_AIRecognition.git`
2. Open the project (e.g., using Qt Creator).
3. Use the pre‑configured [CMakeLists.txt](CMakeLists.txt) to build and run.

## Tech Stack

- **Frontend**: Qt / Qml (cross‑platform)
- **Recognition Capabilities**: Local models & integrated third‑party AI APIs (e.g., Baidu AI, ~~Google ML Kit, TensorFlow Lite, etc.~~)
- **Database**: SQLite (local history storage)
